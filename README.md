# e3d-corp

`e3d-corp` is the company-level runtime for turning signals into evidence-backed opportunities, proposals, decisions, actions, and outcomes.

This repository is being built in phases.

## Phase 1

This phase establishes the repo scaffold, the instance config contract, and the CLI/runtime foundation.

## Usage

```bash
node bin/e3d-corp --help
node bin/e3d-corp config validate examples/instance.example.json
```
